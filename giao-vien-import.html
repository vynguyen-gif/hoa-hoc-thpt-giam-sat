Quản Lý Danh Sách & Cấp Mật Khẩu Riêng Cho Từng Học Sinh

Hệ thống hỗ trợ tự động sinh mật khẩu riêng hoặc đọc mật khẩu từ file Excel có sẵn.

Trang Đăng Nhập Học Sinh

Hai cách để mỗi học sinh có 1 Mật Khẩu (Password) riêng biệt:

1 Cách 1: Hệ thống tự động sinh (Khuyên dùng)

Bạn chỉ cần file Excel 3 cột bình thường (STT, HoTen, TenLop). Hệ thống sẽ tự động tạo mật khẩu riêng ngẫu nhiên, dễ nhớ theo tên từng em (ví dụ: An → An@309, Vy → Vy@707).

2 Cách 2: Bạn tự đặt sẵn trong file Excel

Thêm cột thứ 4 tên là MatKhau (hoặc Password, NgaySinh) trong file Excel. Hệ thống sẽ đọc trực tiếp mật khẩu do bạn chỉ định từ file.

Kéo thả file Excel danh sách lớp vào đây

Hỗ trợ file có cột: STT, HoTen, TenLop (và cột MatKhau tùy chọn)

Danh Sách Học Sinh Kèm Password Riêng Biệt

Mỗi học sinh có 1 mã Username và 1 Mật khẩu riêng, đã lưu vào cơ sở dữ liệu.

PHIẾU TÀI KHOẢN THI TRỰC TUYẾN MÔN HÓA HỌC

Giáo viên cắt theo đường nét đứt để phát cho từng học sinh. Mỗi tài khoản chỉ đăng nhập trên 1 máy.
